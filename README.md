# 🚀 JobAnalytica - AI Job Discovery & Multi-Resume Intelligence Engine

JobAnalytica is a modular production-ready AI job discovery platform, multi-role resume matcher, and application lifecycle Kanban tracker.

## 🌟 Key Features
- **Multi-Resume & Multi-Role AI Fit Engine**: Upload multiple role-specific resumes (Backend, AI/ML, Full Stack) and calculate auto best-fit scores.
- **Universal Company Tier & Scale Discovery**: Ingests across Early Startups, Mid-Cap scaleups, Tier-1 Enterprises, and Tier-3 IT Services.
- **Universal Job Source Adapters**: Greenhouse, Ashby, Lever, and Adzuna adapters with SHA-256 deduplication.
- **Application Kanban Tracker**: Drag-and-drop status tracker with streaming CSV export.
- **Production Hardened & CI/CD**: Helmet security headers, Docker Compose deployment, and GitHub Actions CI/CD.
